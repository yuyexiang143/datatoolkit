# Excel / CSV 数据清洗与报表工具设计

## 目标

为中小企业或个人客户提供一个可从命令行和简单图形界面使用的数据清洗工具。项目必须能被直接演示，包含三类格式读取、可配置清洗、目录合并和异常汇总报表。

## 边界

- 支持 `.xlsx`、`.xls`、`.csv`。
- CSV 优先尝试 UTF-8（含 BOM），再尝试 GBK。
- 清洗规则只覆盖需求中列出的规则，不实现任意公式、跨表关联或可视化图表。
- 命令行和 tkinter 图形界面共用 `core` 与 `report` 中的逻辑。

## 组件

- `datatoolkit/core.py`：文件读取、格式识别、清洗规则、目录合并、表格写出。
- `datatoolkit/report.py`：统计清洗前后差异、分组聚合和异常明细，并写出多 Sheet Excel。
- `datatoolkit/cli.py`：argparse 子命令与终端摘要。
- `datatoolkit/gui.py`：文件/选项选择、执行按钮和滚动日志。
- `sample_data/`：三份同结构脏数据，供演示和端到端验证。
- `tests/`：核心清洗、格式读取、合并和报表的 pytest 测试。

## 数据流

1. 读取器根据扩展名和 CSV 编码候选加载 DataFrame。
2. 清洗器按“字符串去空格 → 金额清洗 → 日期统一 → 空值处理 → 去重”执行。
3. 合并器按目录顺序读取同结构文件，并插入来源文件名列。
4. 报表器先在原始数据上记录空值、无效日期、无效金额和重复行，再执行同一套清洗，最后写出汇总、分组汇总和异常值三个 Sheet。

## 错误处理

- 文件不存在、扩展名不支持、列名不存在、目录没有可合并文件时抛出明确异常。
- 无法解析的非空日期和金额转换为空值，同时进入异常清单。
- CLI 捕获业务异常，向 stderr 输出错误并以非零状态退出。

## 验证

- 测试先于实现编写，并至少覆盖读取、去重、三种空值策略、日期、金额、空白清理、合并和报表。
- 实际生成 `.xlsx`、`.xls`、GBK `.csv` 三份脏数据。
- 实际执行 clean、merge、report 三个 CLI 命令。
- 运行 `pytest -q`，再启动 tkinter 主窗口做进程级冒烟检查。
